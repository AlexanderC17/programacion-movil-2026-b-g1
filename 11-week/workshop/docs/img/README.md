## Cómo capturarlas en Windows

1. Ejecuta la app con Flutter desde `11-week/workshop/app/frontend` y abre la pantalla indicada.
2. En Windows, presiona `Win + Shift + S`, selecciona el área de la ventana de la app y guarda la imagen como PNG.
3. Copia cada archivo en esta carpeta conservando exactamente los nombres de la lista. Para CP4, redimensiona la ventana a 360 px y 768 px de ancho y guarda una captura por tamaño.
4. Comprueba que el texto se lea y que la captura muestre la app completa; no uses mockups ni imágenes de referencia como evidencia.

Si Flutter no arranca por versión, primero instala una versión compatible con el `pubspec.yaml` de `app/frontend` y ejecuta `flutter pub get`; no captures el terminal como si fuera una pantalla de la app.
