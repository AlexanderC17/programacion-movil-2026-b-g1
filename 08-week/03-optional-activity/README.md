# API de Tareas - Semana 08

## Descripción

Esta actividad consiste en desarrollar una API REST utilizando Node.js y Express para gestionar una lista de tareas.

La API permite consultar, crear y completar tareas mediante solicitudes HTTP.

## Tecnologías utilizadas

- Node.js
- Express
- JavaScript
- Thunder Client
- Fetch API
